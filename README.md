## 📘 Overview

This repository is part of the **Data Query with Transact-SQL** course, designed to help beginners understand the fundamentals of SQL. Topics include both querying and modifying data in relational databases across Microsoft SQL Server, Azure SQL Database, Azure Synapse Analytics and Microsoft Fabric covering SQL basics, filtering, joins, functions, data modification and table creation. I have included solutions to exercises and final exam for reference.

## 📂 Repository Contents
- `exercises` – Hands-on labs with suggested answers.
- `final-exam` – Sample final exam questions with answers.
