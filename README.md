## `Overview`

This is a beginner-level course designed to teach the fundamentals of SQL. Topics include both querying and modifying data in relational databases across Microsoft SQL Server, Azure SQL Database, Azure Synapse Analytics, and Microsoft Fabric. It is structured into 11 modules that progressively cover topics such as writing basic queries, sorting and filtering results, combining tables with joins, using built‑in functions, modifying data with INSERT, UPDATE, and DELETE, and creating or altering tables. I have included solutions to both exercises and final exam for reference.
