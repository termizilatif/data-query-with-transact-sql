# Question 18: UNPIVOT

A consultant has sent you sales projections in the following format and you load them into a temporary table named `#forecast`:

| MonthOfYear | Asia | Europe | N.America |
|---|---|---|---|
| 1 | 20125 | 36999 | 27675 |
| 2 | 22165 | 38779 | 29079 |
| 3 | 25149 | 40016 | 31472 |

The sales manager wants the data in this format:

| MonthOfYear | Region | Forecast |
|---|---|---|
| 1 | Asia | 20125 |
| 1 | Europe | 36999 |
| 1 | N.America | 27675 |
| 2 | Asia | 22165 |
| 2 | Europe | 38779 |
| 2 | N.America | 29079 |
| 3 | Asia | 25149 |
| 3 | Europe | 40016 |
| 3 | N.America | 31472 |

Which query returns the correct results?


**Option 1**

```sql
SELECT * FROM
(SELECT Region, Forecast
 FROM #forecast) AS src
PIVOT (SUM(Forecast) FOR Region IN (Asia, Europe, N.America)) AS Pvt
```

**Option 2**

```sql
SELECT MonthOfYear, Region, Forecast
FROM
(SELECT MonthOfYear, Asia, Europe, N.America
 FROM #forecast) AS pvt
UNPIVOT (Forecast FOR Region IN (Asia, Europe, N.America)) AS unpvt
ORDER BY MonthOfYear, Region
```

**Option 3**

```sql
SELECT MonthOfYear, SUM(Asia) AS Asia, SUM(Europe) AS Europe, SUM(N.America) AS N.America
FROM #forecast
GROUP BY ROLLUP;
```

**Option 4**

```sql
SELECT MonthOfYear, SUM(Asia) AS Asia, SUM(Europe) AS Europe, SUM(N.America) AS N.America
FROM #forecast
GROUP BY CUBE;
```

---

**Answer:** Option 2

**Explanation:** UNPIVOT rotates columns into rows; PIVOT does the reverse.
