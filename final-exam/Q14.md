# Question 14: Correlated subquery

The `Sales.Customer` table includes `CustomerID` (integer), `FirstName` (nvarchar(50)) and `LastName` (nvarchar(50)).

The `Sales.SalesOrder` table includes `SalesOrderNumber` (integer), `OrderDate` (date), `CustomerID` (integer) and `Amount` (money).

Some customers have placed multiple orders over a period of years. You write the following query to retrieve the last date on which each customer placed an order:

```sql
SELECT c.CustomerID, c.FirstName, c.LastName,
       -- correlated subquery goes here
       AS LastOrderDate
FROM Sales.Customer AS c;
```

Which subquery should you use to complete the query?


**Option 1**

```sql
(SELECT MAX(o.OrderDate)
 FROM Sales.SalesOrder AS o
 WHERE o.CustomerID = c.CustomerID)
```

**Option 2**

```sql
(SELECT MAX(c.OrderDate)
 FROM Sales.SalesOrder AS c)
```

**Option 3**

```sql
(SELECT o.OrderDate
 FROM Sales.SalesOrder AS o
 WHERE o.CustomerID = c.CustomerID)
```

**Option 4**

```sql
(SELECT MAX(c.OrderDate)
 FROM Sales.Customer AS c)
```

---

**Answer:** Option 1

**Explanation:** The subquery must correlate on o.CustomerID = c.CustomerID and use MAX(o.OrderDate).
