# Question 13: HAVING

You write the following query to return the lowest sales amount for each salesperson.

```sql
SELECT Salesperson, MIN(Amount) AS LowestSale
FROM Sales.vSalesOrders
GROUP BY Salesperson
-- ??? add clause here
```

Which clause should you add so the results include only salespeople whose lowest sales amount is greater than the average sale amount for all sales?

---

**Answer:**

```sql
HAVING MIN(Amount) > (SELECT AVG(Amount) FROM Sales.vSalesOrders)
```

**Explanation:** Group-level filters belong in HAVING; the subquery supplies the overall average.
