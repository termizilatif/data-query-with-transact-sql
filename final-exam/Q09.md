# Question 9: Set operators

You write the following queries to retrieve all customers and customers who have placed orders.

```sql
SELECT CustomerID, FirstName, LastName
FROM Sales.Customer
_____________
SELECT o.CustomerID, c.FirstName, c.LastName
FROM Sales.Order AS o
JOIN Sales.Customer AS c ON o.CustomerID = c.CustomerID
ORDER BY LastName;
```

Which statement should you use to combine the queries so that the results include **only** customers who have not placed any orders?

---

**Answer:** EXCEPT

**Explanation:** EXCEPT returns rows from the first query that are not in the second.

```sql
SELECT CustomerID, FirstName, LastName
FROM Sales.Customer
EXCEPT
SELECT o.CustomerID, c.FirstName, c.LastName
FROM Sales.Order AS o
JOIN Sales.Customer AS c ON o.CustomerID = c.CustomerID
ORDER BY LastName;
```

> **Note:** in T-SQL, `ORDER BY` is only valid after the final query of a set operation, and it applies to the combined result.
