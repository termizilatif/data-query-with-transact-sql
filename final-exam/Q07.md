# Question 7: Date filtering

You write the following query against the `Sales.SalesOrderHeader` table:

```sql
SELECT SalesOrderID, OrderDate, Amount
FROM Sales.SalesOrderHeader
```

You want to limit the results to sales in the first calendar quarter of 2015. Which **two** WHERE clauses can you use? (Assume US date formats, for example `3/31/2015` is March 31st, 2015.)

- **a.** `WHERE OrderDate BETWEEN '1/1/2015' AND '3/31/2015'`
- **b.** `WHERE OrderDate > '1/1/2015' AND OrderDate < '3/31/2015'`
- **c.** `WHERE OrderDate >= '1/1/2015' AND OrderDate <= '3/31/2015'`
- **d.** `WHERE OrderDate BETWEEN '12/31/2014' AND '4/1/2015'`
- **e.** `WHERE OrderDate IN ('1/1/2015', '3/31/2015')`

---

**Answer:** a, c

**Explanation:** BETWEEN and >= / <= include both boundary dates; the other options exclude boundaries, overshoot, or match only two dates.

> **Note:** if `OrderDate` includes a time part, `BETWEEN ... '3/31/2015'` misses orders placed later on 3/31. A safer pattern is `OrderDate >= '1/1/2015' AND OrderDate < '4/1/2015'`.
