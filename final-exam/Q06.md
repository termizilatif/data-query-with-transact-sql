# Question 6: ORDER BY

The `Production.Product` table contains the following columns:

| Column | Type |
|---|---|
| ProductID | integer |
| ProductName | nvarchar(50) |
| ProductCategoryID | integer |
| ListPrice | money |

You write the following query:

```sql
SELECT ProductName, ListPrice FROM Production.Product
```

The results must be in ascending order of `ProductCategoryID`, and products in each category must be sorted with the highest `ListPrice` first. Which ORDER BY clause should you add?

- **a.** `ORDER BY ListPrice, ProductCategoryID`
- **b.** `ORDER BY ProductCategoryID, ListPrice`
- **c.** `ORDER BY ProductCategoryID ASC, ListPrice DESC`
- **d.** `ORDER BY ListPrice DESC`

---

**Answer:** c

**Explanation:** ORDER BY ProductCategoryID ASC, ListPrice DESC.
