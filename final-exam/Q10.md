# Question 10: Outer joins

The sales department occasionally runs promotions that offer a discount on sales orders. Some promotions are associated with a specific product, while others are more general.

`Inventory.Product`:

| Column | Type |
|---|---|
| ProductID | integer |
| ProductName | nvarchar(50) |
| ListPrice | money |

`Sales.Promotion`:

| Column | Type |
|---|---|
| PromotionID | integer |
| StartDate | date |
| EndDate | date |
| ProductID | integer (can be NULL) |
| Discount | decimal |

You write the following query, which returns all product-based promotions and the products they are associated with:

```sql
SELECT prm.StartDate, prm.EndDate, prm.Discount, prd.ProductName, prd.ListPrice
FROM Sales.Promotion AS prm
JOIN Inventory.Product AS prd ON prm.ProductID = prd.ProductID;
```

How should you modify the JOIN so the query returns **all promotions** (NULL `ProductName` and `ListPrice` for promotions without a product) and **all products** (NULL `StartDate`, `EndDate` and `Discount` for products never promoted)?

- **a.** `LEFT OUTER JOIN Inventory.Product AS prd ON prm.ProductID = prd.ProductID;`
- **b.** `FULL OUTER JOIN Inventory.Product AS prd ON prm.ProductID = prd.ProductID;`
- **c.** `RIGHT OUTER JOIN Inventory.Product AS prd ON prm.ProductID = prd.ProductID;`
- **d.** `CROSS JOIN Inventory.Product AS prd;`

---

**Answer:** b

**Explanation:** FULL OUTER JOIN keeps unmatched rows from both tables.
