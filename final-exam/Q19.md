# Question 19: INSERT

The `Sales.Customer` table contains the following columns:

| Column | Data Type | Nullable | Default |
|---|---|---|---|
| CustomerID | integer | No | Identity |
| FirstName | nvarchar(50) | No | |
| MiddleName | nvarchar(50) | Yes | |
| LastName | nvarchar(50) | No | |
| Active | bit | No | 1 |

You want to insert a new record: First Name **Sophia**, Middle Name **none**, Last Name **Garner**, Active **yes**. Which **two** INSERT statements successfully insert the record?


**Option 1**

```sql
INSERT INTO Sales.Customer (FirstName, LastName)
VALUES ('Sophia', 'Garner');
```

**Option 2**

```sql
INSERT INTO Sales.Customer
VALUES ('Sophia', 'Garner');
```

**Option 3**

```sql
INSERT INTO Sales.Customer
VALUES ('Sophia', NULL, 'Garner', DEFAULT);
```

**Option 4**

```sql
INSERT INTO Sales.Customer
VALUES (DEFAULT, 'Sophia', DEFAULT, 'Garner', DEFAULT);
```

**Option 5**

```sql
INSERT INTO Sales.Customer
VALUES (IDENTITY, 'Sophia', NULL, 'Garner', NULL);
```

---

**Answer:** Option 1, Option 3

**Explanation:** Identity values are generated automatically; omit them or list all non-identity columns with NULL/DEFAULT.
