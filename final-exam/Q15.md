# Question 15: Batches and temp tables

You write the following code in SQL Server Management Studio:

```sql
DECLARE @tab AS table(ProductID integer, StockCount integer)
INSERT INTO @tab
SELECT ProductID, InStock + OnOrder
FROM Inventory.Product;
GO
SELECT * FROM @tab;
```

When you execute the code, an error occurs. Which **two** actions could you take to prevent the error?

---

**Answer:**

- Remove the `GO` command
- Use a temporary table named `#tab` instead of the `@tab` table variable

**Explanation:** A table variable exists only for the batch in which it is declared. `GO` ends the batch, so `@tab` no longer exists in the next statement. Either remove `GO` to keep everything in one batch, or use a temporary table (`#tab`), which survives across batches in the same session.
