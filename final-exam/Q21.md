# Question 21: Error handling

You write the following Transact-SQL code, which deletes customers and their orders:

```sql
BEGIN TRY
  BEGIN TRANSACTION
    DELETE FROM Sales.SalesOrder WHERE CustomerID = @CustomerID;
    DELETE FROM Sales.Customer WHERE CustomerID = @CustomerID;
  COMMIT TRANSACTION
END TRY
BEGIN CATCH
  -- code to handle exceptions
END CATCH
```

You want the CATCH block to:

- roll back any transactions in process, and
- re-throw the original exception to the calling application.

`XACT_ABORT` is **not** enabled. Which code block implements the CATCH block correctly?


**Option 1**

```sql
THROW;
```

**Option 2**

```sql
ROLLBACK TRANSACTION
THROW 50001, ERROR_MESSAGE(), 0;
```

**Option 3**

```sql
IF @@TRANCOUNT > 0
  ROLLBACK TRANSACTION
THROW;
```

**Option 4**

```sql
IF ERROR_NUMBER() > 50000
  ROLLBACK TRANSACTION
THROW @@ERROR;
```

---

**Answer:** Option 3

**Explanation:** Check @@TRANCOUNT, roll back, then THROW; to re-throw the original error.
