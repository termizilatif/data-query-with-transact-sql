# Question 20: UPDATE

The `Inventory.Product` table contains `ProductID` (integer), `ProductName` (nvarchar(100)), `ListPrice` (money), `Discontinued` (bit) and `LastUpdated` (datetime).

You want to increase the list price of all non-discontinued products by 10%. The `LastUpdated` column of every modified record must be set to the current date and time. Which UPDATE statement performs the required modification correctly?


**Option 1**

```sql
UPDATE Inventory.Product
SET ListPrice = ListPrice * 1.1,
    Discontinued = 0
WHERE LastUpdated = GETDATE();
```

**Option 2**

```sql
UPDATE Inventory.Product
SET ListPrice = ListPrice * 1.1,
WHERE LastUpdated = GETDATE()
AND Discontinued = 0;
```

**Option 3**

```sql
UPDATE Inventory.Product
SET ListPrice = ListPrice * 1.1,
    LastUpdated = GETDATE(),
    Discontinued = 0;
```

**Option 4**

```sql
UPDATE Inventory.Product
SET ListPrice = ListPrice * 1.1,
    LastUpdated = GETDATE()
WHERE Discontinued = 0;
```

---

**Answer:** Option 4

**Explanation:** Set ListPrice and LastUpdated, filter with WHERE Discontinued = 0.
